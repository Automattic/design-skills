# Brand files

Completed spoken-word brand files live here, one per brand: `{brand}.md`, built from `../brand-file-template.md`.

Three ways to get one:

1. **Bring an existing guide** — a messaging guide, style guide, or voice-and-tone doc. The agent reads it in full, distils it into this shape, records where it came from, and asks you only about the gaps (SKILL.md, Step 0). Written guides rarely cover pacing, pronunciation, voice identity, or consent, so expect those to be the remaining questions.
2. **Answer the interview** — six questions, and the agent writes the file.
3. **Fill the template yourself** — about ten minutes.

See `../GUIDELINES.md`, Path B.
